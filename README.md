# Sriniketh Bobbili

A minimalist personal site for software, AI, and projects.

Tagline: "Building software and learning in public."

## Stack

- React
- Vite
- Tailwind CSS
- Project cards

## Commands

```bash
npm install
npm run dev
npm run build
npm run deploy
```

## Content

Project entries are stored in `src/data/projects.js`.
